# Helix 1.0.1

本地项目命名体验更新，兼容 `1.0.0` 的现有数据。

## 更新内容

- 新建项目时同时填写项目名称和首阶段名称，不再自动使用“项目启动”。
- 已有项目可在关系图中重命名，并安全写回 Project Markdown 一级标题。
- 已有阶段可在卡片中重命名，并安全写回带阶段编号的 Stage Markdown 一级标题。
- 用户直接修改 Project／Stage Markdown 一级标题后，关系图会在稳定扫描后自动采用新名称。
- 重命名会同步刷新 Helix 管理的 Canvas 摘要；文件路径、稳定 ID、用户正文、关系和布局保持不变。

## 数据与迁移

- 无需迁移；直接从 `1.0.0` 更新即可。
- Markdown 和 Canvas 仍是唯一真值，写入继续使用 revision／CAS 竞争保护。
- 不会覆盖未知 YAML、用户正文、模板或非 Helix 管理的 Canvas 内容。

## 已知限制

- 滴答网络同步、远端写入合同及项目投影入口仍关闭；已保存的 API 口令继续保留在 Obsidian SecretStorage。
- 本地任务暂不支持跨 Stage／项目移动。
- 仅支持 Obsidian `1.12.2` 及以上桌面端，不支持移动端。

## 上游与许可证

- 本版本未引入新的上游代码。
- 第三方归属与完整许可证见 Release 附件。
