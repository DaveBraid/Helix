## 当前事实

- 普通任务与远端清单仍以滴答为权威；项目计划行动及本地子任务以所属 Stage Markdown 为唯一真值。
- Project／Stage Markdown 保存项目身份、状态和正文；专用 Canvas 保存继承／分支／合并关系与布局；`data.json` 不保存项目或本地任务影子真值。
- Stage `# 计划行动` 中的顶层清单项自动进入任务页，缩进项作为子任务；合法原生清单项首次读取时静默补稳定身份，空模板占位保持原样。
- 本地任务支持标题、备注、五种状态、起止时间、时区、全天、优先级、标签及直接子任务；一次保存使用同一 Stage revision 做 CAS，竞争时拒绝覆盖。
- Obsidian 原生勾选本地行动会收敛为“已完成”，取消勾选恢复“想法”；隐藏身份和属性标记不会出现在 Live Preview。
- 首页、任务列表、搜索、状态筛选、日期视图和四象限共用本地任务即时投影；本地操作不进入滴答队列。
- 普通滴答任务与本地项目任务共用紧凑编辑器外壳；滴答低频属性折叠显示，本地编辑器直接提供子任务区。
- 聚焦桥接仍以 Canvas 入边为关系源，支持继承、分支、合并、反向编辑和同窗竞争冲突。
- 当前版本不展示项目滴答投影入口；统一门禁覆盖后台扫描、队列、恢复、重试和冲突写回。
- 凭证仅存 SecretStorage；版本为 `0.1.6`，最低 Obsidian 桌面端 `1.12.2`。
- 冲突中心左栏只用于定位真实任务、项目和聚焦桥接冲突；右栏复用原有 Base／Local／Remote 逐字段选择与应用逻辑。恢复和投影诊断保留原有只读／受门禁操作，不新增忽略或批量动作。
