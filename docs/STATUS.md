## 本轮目标

- 用真实子任务表达“项目父任务—Stage 行动”，复用普通任务队列完成安全的 Helix→滴答单向投影。
- 非目标：不发布版本；不修改正式 Vault；不触碰用户既有滴答对象；能力合同与专用实测通过前不开放项目投影入口。

## 当前事实

- Project／Stage Markdown 保存身份、状态和正文；专用 Canvas 保存关系及布局；`data.json` 不保存项目真值。
- Stage `# 计划行动` 顶层清单项进入任务页，缩进项作为本地子任务；项目投影仍由发布门禁关闭。
- 滴答能力分为只读、普通任务写入、专用合同和项目投影四层；当前前三层代码开放，项目投影硬关闭。
- 普通任务 CRUD、跨清单移动、完成／重开、逐字段冲突、重启队列、后台同步及真实父子关系已有独立合同或真实闭环。
- 合同 v9 独立验证 `taskParentingVerified`；能力成立且字段显式选择时才可发送 `parentId`，解除关系使用最小 `parentId=""`。
- 项目父级是带稳定 marker 的普通滴答 Task；Stage 行动已改为带稳定 `parentId` 和 marker 的普通子 Task，不再写父任务 `items`。
- 远端结果未知禁止重发；本地与远端同字段竞争必须保留 Base／Local／Remote 并逐字段人工选择。
- 版本 `1.0.1`，最低 Obsidian 桌面端 `1.12.2`；本阶段不发布。

## 本轮改动

- 项目投影 readiness 改为要求真实父子任务与看板归栏能力，不再依赖检查项能力。
- 项目行动创建、改名、状态变化、删除改走现有任务队列；写后核验 Task ID、`parentId`、清单、分栏、marker 和状态。
- 子任务创建使用稳定 client identity；未知结果、Markdown CAS 竞争和远端竞争持久冻结，不按标题领养或自动重发。
- 删除旧 items 生产同步分支与 66 个失效回归，新增真实子任务创建、更新、完成／重开、删除、冲突、未知结果与跨项目状态测试。
- 架构文档已更新为 v9、140 次主体预算及真实子任务唯一生产模型。
- 写入成功后不信任会剥离看板字段的普通缓存收据，统一按精确 Task ID 再读后才核验并落账。
- 未知更新与删除只允许依据现有收据、冲突审计和精确远端结果只读收口；不会续发写入。
- Stage 行动备注、起止日期、时区、全天、优先级和标签已映射到普通任务属性并纳入 Base／Local／Remote 冲突。
- 旧 items 账本、队列和冲突永久只读隔离，即使未来开放项目投影也不会进入 drain、重试或写回。
