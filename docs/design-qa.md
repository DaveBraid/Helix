## 已确认

- 左侧入口名称为“挑战”；顶部“正在进行”显示最多三项、所属项目和展开入口。
- 项目页的关系图、卡片和看板均可切换；项目和阶段卡片只是摘要入口，点击后打开 Markdown。
- 关系图支持缩放、适应全部、空格平移、多选和拖动；拖动时连线实时更新。
- Canvas 节点的宽高和坐标会忠实投影到内嵌关系图；项目状态在项目条和项目卡片中可见。
- 顶部只保留“新建项目”。阶段卡片右侧中部在悬停或选中时显示加号；单卡点击已经确定来源，并按当前后继直接推断继承或分支，不再弹出关系和前置阶段选单。
- 新阶段弹窗只显示自动编号、推断后的关系摘要和阶段标题输入；第一次点击创建继承，第二次从同一来源点击时把既有继承转换成分支并创建一个新阶段。
- 关系图中多选两个及以上阶段后点击其中一个加号，直接进入合并标题输入；合并摘要按当前拖动位置排列来源，并预告哪些来源的既有继承会改为分支。跨项目合并明确显示目标项目名、外部来源及安全确认。
- 已有连线可选择，画布底部显示关系摘要和“修改或删除”；关系弹窗可以更改类型、前置阶段或二次确认删除。
- 阶段卡片右上角在悬停或选中时显示删除入口；删除弹窗清楚说明 Markdown 与 Canvas 影响并要求勾选确认。

- 最新精确构建已从阶段 7、阶段 8 的加号分别验证分支和继承摘要：弹窗自动聚焦标题输入，只保留取消与创建按钮，不再出现关系或前置阶段选单。
