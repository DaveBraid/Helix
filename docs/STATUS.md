## 当前事实

- 滴答清单仍是任务、远端清单、习惯和专注记录的权威源；普通任务双向同步以及专注时长读取已可用。
- Project/Stage Markdown 保存项目身份、状态与正文，Canvas 保存关系与布局；项目页只投影这些 Obsidian 原生数据。谱系已支持继承、分支、合并、多入链、折叠和整理。
- 复盘支持日／周／月／年模板、创建和回看；分析与挑战只消费事件账本。
- 项目向滴答是 Helix → 滴答的单向投影：项目映射父任务，阶段计划行动映射子任务；滴答侧变化不会自动反写 Markdown。
- 投影设置页、项目行动面板和冲突中心均已接入显式 UI；可精确选择清单／分栏、二次确认激活、显式纳管和编辑五状态、手动同步单个项目并严格复核冻结对象。
- 项目投影默认关闭，不注册自动同步；任何同步都必须由用户显式触发，标题或同名对象不得用于猜测身份。
- 合同版本为 v6；独立 `columnCreateVerified` 与其他能力均以不可逆授权绑定缓存，授权变化、过期或测试残留会使其失效。
- 缺失的 `Helix项目` 分栏只能在设置页预览并二次确认创建；完整事务独占远端门，写前持久 running，单发请求，写后双源精确复读。
- 分栏 checkpoint 不含凭证：prepared 证明未发送并可安全清除；running 中断或结果不明转 unknown。冲突中心只复读并精确领养，不重发、不删除、不改名、不重排任何列。
- 分栏创建成功后自动选中新列，但必须重新预览才能激活；归属、同名、队列、能力或 unknown 阻塞均零写入。
- 凭证只存 Obsidian SecretStorage；`data.json`、Markdown、日志、Notice、测试夹具和 Git 均不得出现口令。
