## 当前事实

- Project／Stage Markdown 保存身份、状态和正文；专用 Canvas 保存关系及布局；`data.json` 不保存项目真值。
- 新建项目必须同时填写项目名与首阶段名；项目和阶段可从关系图重命名，按 revision／CAS 原子写回 Markdown 标题与 Canvas 摘要；用户直接修改 Markdown 一级标题也会经稳定扫描反映到关系图。
- Stage `# 计划行动` 的顶层清单项自动进入任务页，缩进项作为子任务；首次读取会静默补稳定身份，空模板占位保持原样。
- 本地任务详情采用 Dense task canvas，支持日期月历、无时间／时间点／时间段及子任务增删改排；全部通过 Stage revision/CAS 写回原 Markdown，不建立第二份真值。
- Stage／Project 正文输入期间不运行派生项目扫描；失焦后合并刷新；后台 Helix 标签不抢编辑焦点。
- 聚焦桥接以 Canvas 入边为关系源，支持推进、分支、合并、反向编辑及同窗竞争冲突。
- 聚焦引用上下各留一空行；Live Preview 隐藏技术标记。
- `helix-sequence` 保持物理文件高水位且不复用；`helix-stage-code` 按当前继承／分支／合并图维护，删除会原子更新现存 Stage 标题、属性、聚焦引用及 Canvas 编号索引。
- 冲突中心分级展示；文本使用真实行号 IDE diff，标量属性按需展开。
- `dev` 已把滴答能力拆成只读、普通任务写入、专用合同测试、项目投影四层；当前仅只读门禁开放，其他三层硬关闭，口令保留在 SecretStorage。
- 只读开放而普通写入关闭时，`sync()` 强制 pull-only；离线队列不被认领、重试或改变。服务层独立拒绝普通写入、合同写入与项目投影，界面和命令按对应能力隐藏。
