# 阶段 2 计划：五列阶段看板与状态视觉

## 目标

- 阶段看板为想法、进行中、已完成、已暂停、已终止五列，只展示阶段卡片。
- 五列固定在同一横排且不换行；列内卡片纵向排列，宽度不足时仅看板区域横向滚动。
- 卡片可直接拖入另一列，无确认弹窗；落点即表示新状态。
- 图谱、卡片列表和看板共用同一状态样式映射：图标、颜色、文案一致。

## 交互合同

- 拖起：原卡片半透明，显示跟手影子；可用列轮廓与计数即时响应。
- 经过：目标列出现低调高亮和插入位置提示，禁用列明确拒绝。
- 落下：先执行 Markdown CAS，成功后卡片平滑移入新列；失败回弹原列并提示真实原因，不伪造成功。
- 落回原列、取消和经过不写入。
- 键盘用户可从卡片打开状态候选或用快捷键移动，复用同一提交入口。
- `prefers-reduced-motion` 下取消位移动画，保留轮廓反馈。

## 验收

- 五列数量、筛选、旧 `closed` 兼容和所有状态卡片符号/颜色正确。
- 桌面宽屏与窄窗下五列均不折行，窄窗只出现看板自身的横向滚动，不带动固定侧栏。
- 拖拽成功、CAS 竞争、落回原列、取消、连续快速拖拽和键盘路径有测试。
- 无乐观数据真值；不写 Canvas 状态，不改关系和布局。
- Obsidian CLI 实机验证布局、夜间模式、拖拽动画和零控制台错误。

## 非目标

- 不在本阶段展示计划行动子任务，不同步滴答。
