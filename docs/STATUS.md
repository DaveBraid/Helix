## 已完成

- 建立独立 Git 仓库、中文开发文档、构建、Vitest 与 BRAT 产物检查。
- 固定审查 `CYZice/Obsidian-DidaSync@c33aedd`，隔离滴答适配层并保留 MIT 归属。
- 实现滴答任务、清单、习惯和专注接口，运行时正规化、能力探测、超时和错误分类。
- 实现 Base/Local/Remote 快照、逐字段手动冲突、时间字段组、写前复查、写后验证与脱敏审计。
- 冲突应用使用服务层单飞与持久 `applying` 原子认领；重复点击或多视图并发不能重复创建远端记录。
- `applying` 状态锁定所有字段选择；未知远端结果不会永久失去处理入口，但只有用户在滴答中确认未写入后才能显式解锁。
- `applying` 也支持“远端已生效”复读采纳；远端删除后本地重建若创建成功但复读未知，会保持锁定并要求填写/核对新 ID，不会再次创建。
- 实现持久离线队列；创建、移动和完成结果未知时禁止盲目重试，进入人工核对。
- 启动时会把中断的 `running` 操作持久转换为人工核对；失败或阻塞操作在冲突中心可见，单个耗尽操作不会阻塞其他对象。
- 数据存储读取等待写链，队列 drain 使用单消费者锁，所有队列状态转换都基于最新持久状态原子修改，避免交错入队时丢操作或重复消费。
- 同一对象的队列因果顺序按持久数组位置判定，相同时间戳也不会让后续操作越过前序操作。
- 远端删除与本地修改冲突支持选择本地后用新 ID 重建，并迁移后续队列和“正在进行”标记。
- 已有滴答任务可在工作台完成、改名和移动清单，写入仍经过离线队列及三方冲突闸门。
- “正在进行”标记会在普通创建获得远端 ID、任务本地移动或远端移动时同步更新；展示时以当前任务所属项目为准。
- Helix 发起且经远端验证的任务完成会立即写入事件账本，不会因超过近期完成项窗口而漏记；Cycle 关闭后运行时统计立即刷新。
- 实现稳定项目、不可变 Cycle、日周月年复盘模板、事件账本、统计、XP、成就及确定性周/月挑战。
- 周记使用 ISO week-year；已关闭复盘会在启动时幂等补齐账本事件，避免文件已关闭但统计缺失。
- 挑战奖励按当前可逆事件重新校验；任务重开或专注删除导致进度跌破目标时自动回收奖励。
- 挑战达标事件冻结指标、目标、周期边界、奖励与规则版本；更新挑战池不会追溯改变历史 XP。
- 任务完成和复盘关闭共用即时挑战评估入口，达标奖励与等级变化无需等待下一次滴答同步。
- 项目创建与 Cycle 推进可重入恢复；发现同名非 Helix 文件或不匹配的下一轮时拒绝覆盖。
- 实现项目笔记与唯一主 Canvas 谱系同步，Helix 只管理带标记的节点和边，并执行 DAG 校验。
- Canvas 在真实 `helixProjectId` 层执行 DAG，拒绝重复项目节点和不存在的项目；全库重复 `helix-id`、重复滴答映射及悬空父项目都会持久冻结并显式提示。
- Canvas 批量写回项目笔记先规划全部文件，任一比较写入失败会反向回滚本轮成功写入；自写标记只在比较成功后登记，避免吞掉真实用户修改事件。
- 谱系写入使用串行队列；写入期间到达的项目或 Canvas 用户修改会在本轮之后继续处理，插件自身写入事件会被单独识别，避免丢改动或自触发循环。
- Canvas 与项目笔记在同一防抖窗口内都变化时，持久暂停到冲突中心，由用户明确选择哪一侧为准。
- 用户在两个 Helix 项目节点之间手绘的无标签边会被纳入谱系并执行 DAG 校验。
- 新手绘边若导致环，会在再次比较 Canvas 版本后只撤销该边并给出可见提示。
- 习惯与专注删除只在本轮 31 天查询覆盖区间内推断；自然滑出窗口不会回收历史统计。
- 冲突侧栏徽标汇总字段冲突、待核对、失败及阻塞队列；中断恢复会显示通知，孤立队列可复制脱敏诊断摘要。
- 实现桌面工作台：今日、任务、项目看板/列表、复盘、分析、挑战、冲突中心。
- “正在进行”为 Helix 独立标记，首页最多显示 3 项并提供“展开全部”，同时显示所属项目。
- 项目页可以创建项目与 Cycle 01；挑战采用深色霓虹本周挑战卡；左侧入口名称为“挑战”。
- “测试连接”为纯只读能力探测，不会消费离线队列或执行远端写入。
- 项目、习惯、专注接口即使返回 HTTP 200，只要集合不是数组也会判为不可用；所有会进入任务/事件账本的日期先正规化并拒绝非法值。
- 快照值使用完整 SHA-256 校验，确定性事件 ID 也使用 64 个十六进制字符的摘要；载入时交叉验证快照实体 ID、队列操作类型、冲突重算字段及 staged/applying 完整性。
- `data.json` 已升级到 schema 2：schema 1 旧哈希先验证再迁移，旧事件按语义换算 ID 并去重；集合重复 ID、伪造事件 ID、坏挑战载荷和悬空阻塞引用都会进入只读恢复。
- 插件卸载会终止尚未开始的同步、队列和谱系工作；谱系监听覆盖项目与 Canvas 的创建、修改、删除和重命名。
- 数据存储使用跨重载代际栅栏：旧实例的在途保存先于新实例读取完成，代际失效后禁止旧服务、队列引擎或存储覆盖新状态。
- 发布载荷包含 ECharts、NOTICE、ZRender 与 d3 的完整许可证，并由 `release:check` 强制校验。
