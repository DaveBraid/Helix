- 进行中 Stage 内仍为 `idea` 的未完成行动在任务页继承为“进行中”；显式完成、暂停、终止保持自身状态。
- 滴答写入需要 API 口令、当前 Vault／授权／合同版本对应的能力缓存及自动同步开关同时满足。
- 正常设置区可直接验证写入能力；首次验证通过自动开启同步，已验证但关闭同步时提供“开启自动同步”。开发合同入口仍隔离在折叠区。
