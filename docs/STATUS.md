## 当前事实

- 普通任务双向同步、滴答清单列表／看板呈现及专注时长读取已可用；滴答仍是任务、清单、习惯和专注记录的权威源。
- Project／Stage Markdown 保存项目身份、状态与正文，Canvas 保存继承／分支／合并关系和布局；项目页只投影 Obsidian 原生数据。
- 复盘支持日／周／月／年模板、创建和回看；分析与挑战只消费事件账本。
- 项目向滴答目前是显式单向投影：项目映射父任务，阶段计划行动映射子任务；滴答变化不自动反写 Markdown。
- 项目投影默认关闭；清单、分栏和稳定远端 ID 必须显式选择，标题或同名对象不得用于猜测身份。
- 合同版本 v6；任务 CRUD、提醒、重复、父子、重开、看板归栏和分栏创建能力分别验证并绑定授权，残留或授权变化使能力失效。
- 4D 在首个远端 create 前持久化合法空 placeholder，随后逐步扩充稳定身份、候选范围和列基线；pending 在排他门内复查并零远端调用阻断新合同。
- 4D 恢复独占远端门，任务先于清单逐项精确复读和 CAS 收口；删除结果未知只复读、不重发。
- 旧版无 plan 残留只能显式领养唯一 A/B 运行组；多个组、普通对象、列竞争或身份歧义均拒绝删除。
- 凭证只存 Obsidian SecretStorage；清理计划、界面和普通诊断均不得披露口令、临时对象 ID 或唯一标记。

## 本轮改动

- `dida-contract-cleanup` 领域／服务：严格 plan、旧残留领养、限流只读复核、任务优先与清单后置清理、unknown 永久禁重发。
- `write-contract`／`helix-service`：报告准确追踪残留，持久化 pending，新合同前置阻塞，提供排他领养／恢复入口。
- `storage/model`：严格校验授权绑定、运行身份、A/B 名称、完整列、候选归属和 unknown 状态。
- 冲突中心与命令面板：重载后仍可双确认严格领养；失败提示固定脱敏，不显示稳定 ID、marker 或底层错误。
- 自动化测试覆盖持久化、重启继续、部分清理、限流、删除结果未知禁重发、项目竞争、多运行组拒绝和 pending 零远端调用。
