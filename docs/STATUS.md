## 当前事实

- 滴答清单是任务、远端清单、习惯和专注记录的权威源；Markdown/Canvas 是 Helix 项目、阶段正文、关系和布局的权威源，见 [ARCHITECTURE.md](ARCHITECTURE.md)。
- 任务工作台可读取真实清单、任务和专注记录，并提供列表/看板、拖放、单击标题编辑和 `~`、`#`、`!` 快捷属性；后续任务日常管理以滴答 App 为准。
- 合同唯一权威版本为 4；旧版本或不同授权绑定的缓存一律失效为只读。提醒、重复和父子能力保持只读；基础 CRUD、跨清单移动和看板归栏已有真实合同证据。
- 两轮真实 v4 合同创建的专用对象都已按精确身份单次清理，并以只读复核证明零残留；未触及用户任何既有任务、清单或配置。
- 跨清单移动采用 DidaSync 归属的单元素数组载荷并单发；后续只读复核源/目标清单，不依赖响应正文或对象载荷回退。
- 生产写入必须持有当前授权的有效合同；合同启动即持久撤销旧能力，失败、残留、身份不明或重载后均保持只读。同步仍可拉取，待写队列不会被排空或重发。
- 显式查询限流仅允许只读等待复核；非幂等写入一律单发。任何未知远端结果冻结为待核对，不能解锁重试，只能在滴答 App 核对后复读采纳。
- `columnName` 是只读看板派生字段；`status` 与 `completedTime` 在本阶段由滴答 App 管理，不进入可写三方冲突或普通更新。普通完成仍走独立完成操作。
- CLI 与设置页合同确认相互隔离，15 秒失效且运行单飞；插件卸载后静默。
- 设置页把可能真实写入的写入合同测试及其能力状态置于默认折叠且键盘可达的“开发测试”区；日常授权、只读拉取和同步配置保持常规可见。
