- 滴答能力分为只读、普通任务写入、专用合同和项目投影四层；当前前三层代码开放，项目投影硬关闭。

- 合同 v9 新增独立 `taskParentingVerified`：仅在能力成立时写载荷可包含 `parentId`，解除父子关系使用最小 `parentId=""`。
