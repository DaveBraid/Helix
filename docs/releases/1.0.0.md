# Helix 1.0.0

Helix 的首个本地正式版，面向 Obsidian 桌面端科研项目管理与结构化复盘。

## 主要能力

- 以 Project／Stage Markdown 为内容真值、专用 Canvas 为关系与布局真值的项目系统。
- 推进、分支、合并三类阶段关系，支持布局保存、局部整理、折叠、删除与聚焦。
- Stage“计划行动”自动进入任务页，支持本地任务、子任务、状态、日期、时间与标签编辑。
- 日／周／月／年复盘模板，任务统计、热力图、趋势与挑战系统。
- Markdown／Canvas revision 与 CAS 保护，以及逐字段人工冲突处理。

## 数据与迁移

- 项目和阶段内容继续保存在用户指定的 Markdown 目录，关系与布局保存在 Helix 专用 Canvas。
- 模板默认位于 `Template/Helix/`，只补齐缺失模板，不覆盖用户修改。
- 从 0.1.x 升级无需批量迁移；Helix 不会用发布过程覆盖用户 Markdown、Canvas 或模板。

## 已知限制

- 本版本为本地正式版，所有滴答网络同步、远端写入合同及项目投影入口均关闭；已保存的 API 口令仍保留在 Obsidian SecretStorage。
- 本地任务暂不支持跨 Stage／项目移动。
- 仅支持 Obsidian `1.12.2` 及以上桌面端，不支持移动端。

## 上游与许可证

- 滴答适配层保留 DidaSync `CYZice/Obsidian-DidaSync@c33aedd` 的 MIT 来源说明，但 1.0.0 不开放网络同步。
- 项目交互参考 Research Card Manager；第三方归属与完整许可证见 Release 附件。
