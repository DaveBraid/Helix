## 当前事实

- Project／Stage Markdown 是项目身份、状态和正文的权威源；专用 Canvas 是关系和布局的权威源。
- main 的 Shift 同轴吸附、容器级整理、保存布局读取、关系中插、分支编号槽位、项目颜色编辑和单箭头悬停加号均已保留。
- Stage `# 计划行动`直接进入任务页，缩进项形成任意深度本地任务树；写回使用 Stage revision CAS。
- Stage 父任务和行动以 Markdown 状态为本地完成真值；已映射 Stage 下的新行动会立即沿用父任务所在的滴答清单呈现。
- 任务树父节点使用 44px 环形进度／完成勾，叶节点使用 24px 完成圆；折叠入口位于右侧，子级缩进为 18px。
- 普通滴答任务、Stage 行动和项目投影父任务共用统一任务详情页，不建立第二份任务真值。
- 滴答读取、普通任务写入、合同测试和项目投影使用独立发布能力门禁；自动同步和项目投影仍要求显式配置及运行时 readiness。
- 项目投影复用 `HelixService`、唯一离线队列、共享远端写门和冲突合并管线，不另建远端写入引擎。
- 旧 Task Reference Markdown 保持原文件不动，但运行时服务和测试已由 dev 删除。
- 当前版本文件仍为 `1.0.2`，最低 Obsidian `1.12.2`；本轮不生成 Release。
