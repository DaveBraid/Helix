# 阶段 5 计划：本地任务体验（已完成）

## 目标

- Stage Markdown 的“计划行动”是本地项目任务的唯一真值；项目行动自动进入任务页，不复制到 `data.json`。
- 支持任务的稳定身份、状态、标题和子任务，在项目页、任务页与 Markdown 之间即时一致。
- 普通滴答任务与本地项目任务共用一套紧凑编辑器外壳，按来源显示可用能力；本阶段不进行任何滴答写入。

## 数据合同

- 顶层行动和子任务都保存在所属 Stage 的“计划行动”小节。
- Helix 只为清单项补充 Live Preview 隐藏的稳定身份与状态标记；未知正文和小节外内容保持不变。
- 子任务通过 Markdown 缩进和显式父身份校验归属；禁止跨 Stage 猜测父级。
- 所有编辑先读取 revision，再以 CAS 修改精确 Stage 文件；竞争时拒绝覆盖并刷新。

## 分段

1. 清空测试 Vault 的 Helix 业务数据；保留模板、插件设置、SecretStorage 口令和远端安全控制记录。
2. 扩展计划行动领域模型与仓库操作，自动纳管有效清单项并生成任务快照。
3. 任务页合并展示滴答任务和本地项目任务；本地任务操作只写 Stage Markdown。
4. 重构统一任务编辑器：标题／备注为主区，日期、状态、优先级、标签、项目等属性使用紧凑控件；子任务内联增删改。
5. 完成领域测试、工作区 CAS 测试、Obsidian CLI 实机验收及文档快照；不升版本、不发布。

## 非目标

- 不恢复 Helix 项目到滴答的投影。
- 不修改、移动、完成或删除任何真实滴答对象。
- 不在 `data.json` 新增本地任务影子库。
