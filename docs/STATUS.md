## 当前事实

- 普通滴答任务、清单、习惯和专注以滴答为权威；项目计划行动及本地子任务以所属 Stage Markdown 为唯一真值。
- Project／Stage Markdown 保存项目身份、状态和正文；专用 Canvas 保存继承／分支／合并及布局；`data.json` 不保存项目影子真值。
- Stage `# 计划行动` 的顶层清单项自动进入任务页，缩进项作为子任务；首次读取会静默补稳定身份，空模板占位保持原样。
- 本地任务支持标题、备注、五种状态、起止时间、时区、全天、优先级、标签及直接子任务；保存使用同一 Stage revision 做 CAS。
- 原生勾选本地行动会收敛为“已完成”，取消勾选恢复“想法”；隐藏身份与属性标记不出现在 Live Preview。
- 首页、任务列表、搜索、状态筛选、日期视图和四象限共用本地任务即时投影；本地操作不进入滴答队列。
- 聚焦桥接以 Canvas 入边为关系源，支持继承、分支、合并、反向编辑及同窗竞争冲突。
- 冲突中心按“需要你选择／等待远端核对／仅需检查”分组；任务与项目使用 Base／Local／Remote 逐字段合并，聚焦使用 Base／来源／派生正文合并。
- 当前版本不展示项目滴答投影入口；统一门禁覆盖后台扫描、队列、恢复、重试和冲突写回。
- 凭证只存 SecretStorage；版本 `0.1.6`，最低 Obsidian 桌面端 `1.12.2`。
