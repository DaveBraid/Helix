# Helix 1.0.2

本地项目关系图体验更新，兼容 `1.0.1` 的现有 Markdown 与 Canvas 数据。

## 更新内容

- Shift 拖动阶段卡片时支持同轴位置吸附；局部整理以完整项目容器作为碰撞边界。
- 新增“读取保存布局”，可恢复最近一次写入 Canvas 的布局。
- 可在关系箭头中点直接插入阶段，自动保持推进关系并按 DAG 更新阶段编号；分支中插会保留原目标的编号槽位。
- 创建阶段窗口显示真实阶段编号，包括 `2.1`、`2.2` 等分支编号。
- 项目编辑窗口支持同时修改名称与主题颜色。
- 关系箭头移除中文标签，扩大隐形命中范围；悬停当前箭头时以动画显示灰白插入按钮。

## 数据与迁移

- 无需迁移；直接从 `1.0.1` 更新即可。
- Markdown 与 Canvas 仍是唯一真值，不创建项目影子数据。
- 阶段编号调整、聚焦引用与 Canvas 更新继续使用 revision／CAS 竞争保护。
- 不会覆盖未知 YAML、用户正文、模板或非 Helix 管理的 Canvas 内容。

## 已知限制

- 滴答网络同步、远端写入合同及项目投影入口仍关闭；已保存的 API 口令继续保留在 Obsidian SecretStorage。
- 本地任务暂不支持跨 Stage／项目移动。
- 仅支持 Obsidian `1.12.2` 及以上桌面端，不支持移动端。

## 上游与许可证

- 本版本未引入新的上游代码。
- 第三方归属与完整许可证见 Release 附件。
