## 当前事实

- 任务、清单、习惯和专注记录以滴答为权威源；同步、列表／看板及专注读取已有实现。
- Project／Stage Markdown 保存项目身份、状态和正文，专用 Canvas 保存继承／分支／合并关系及布局；`data.json` 不保存项目影子真值。
- 项目行动现投影为一个项目父任务内的检查项；项目本身不再作为 Canvas 节点，旧 `parentId` 子任务路径不是 v7 合同。
- items 保留远端顺序、标题／日期字面量、不安全 `sortOrder` 和未知字段；不能无损回写时冻结。
- 三类写入发送前持久化稳定 operation ID、有序基线及逐项证明；成功后清除操作 ID。
- 写入使用刚复读的父任务作 Base；精确入队禁止合并。无 ID 追加在确认未发送的竞争中先持久化最新 Base，再以同一 ID 续发。
- Base／Local／Remote 同字段竞争须人工解决；收口要求审计与最终快照哈希一致，unknown 不得盲目重发。
- owned item 只允许标题与 `0/2` 状态变化；`0→2` 必须得到合法 `completedTime`，`2→0` 必须清除，状态不变时该字段必须不变。
- owned 冲突持久化精确 item ID，标题安全规则只约束该 ID；普通 items 的标题字面量、未知字段和顺序保持不变。人工选择保留删除对象时恢复 Markdown 与 ledger。
- 项目投影默认关闭，启用须二次确认，并复用唯一队列与 `RemoteWriteGate`。
- 凭证只存 SecretStorage；请求治理、授权切换闭锁及合同主体／清理独立预算仍有效。
