# 阶段 4 计划：Helix 项目向滴答的单向投影

## 目标

- 一个 Helix Project 投影为滴答“科研”清单中“Helix项目”看板列的一个父任务。
- Stage `# 计划行动` 下的受管 Markdown 任务投影为对应项目父任务的子任务。
- 只实现 Helix → 滴答；滴答变更不反写 Markdown，但写前/写后仍精确复读以防覆盖竞争。
- 复用现有 Helix 任务正规化、写入队列、授权合同、父子能力、看板归栏、未知结果和冲突管线；禁止建第二套同步引擎。

## 配置与身份

- 设置保存精确的目标滴答清单 ID 和目标列 ID；“科研”和“Helix项目”仅作首次配置建议，不在同名或身份不明时自动选择。
- 开启前展示精确清单、列和将创建的对象；没有列时只在用户显式启用后单发创建“Helix项目”，不修改其他列。
- Project Markdown 只保存已复读的滴答父任务 ID；每条计划行动通过 Live Preview 隐藏的受管 HTML 注释保存本地 UUID、状态和已复读子任务 ID。
- `data.json` 只保存队列、Base/Local/Remote 快照和未知结果状态，不成为项目或行动映射真值。

## 增删改合同

- 增：Markdown 先 CAS 分配本地 UUID；只发一次创建，写后精确复读 ID/父级/清单/列/标题，再 CAS 回填远程 ID。回填竞争进入人工关联，不重发创建。
- 改：只从 Markdown 受管行动生成字段意图，复用现有任务更新白名单、写前复查与写后验证。
- 状态：`completed` 映射滴答完成；`idea/active/paused/terminated` 在滴答均保持开放，其 Helix 状态不伪装成滴答原生状态。终止是 Helix 语义，不自动完成或删除远程任务。
- 删：删除受管行动会产生持久 tombstone；仅在子任务 ID、父任务 ID、目标清单与唯一标记全部复读一致时删除。远程结果未知时冻结 tombstone 并人工核对，不重发。
- Project 文件或阶段文件删除不级联删除滴答清单、列或其他用户任务。

## 验收与真实测试边界

- 先用伪远程覆盖增删改、父子映射、列归属、授权过期、冲突、CAS 竞争、网络中断和重启恢复。
- 真实合同只使用 Helix 唯一标记的临时清单/列/父子任务，精确清理；不在“科研”清单调试。
- 生产激活前只读复读唯一“科研”清单；创建目标列是用户请求的生产配置动作，不归入开发清理。
- 待写队列非空、能力合同过期、目标看板过期或有残留未知时禁止激活。

## 非目标

- 不实现滴答 → Markdown 反向同步，不按标题搜索并领养任务，不批量删除，不变更“科研”清单的其他配置。
