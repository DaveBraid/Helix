## 本轮目标

- 让普通滴答任务可独立关联 Helix 项目／阶段，并补齐项目页展示与复盘统计闭环。
- 非目标：不发布版本，不开放项目投影，不执行滴答写入，不修改正式 Vault。

## 当前事实

- 任务、清单、习惯和专注记录以滴答为权威源；任务同步、列表／看板和专注记录读取已有实现，当前可继续使用滴答 App 管理任务。
- Project／Stage Markdown 保存项目身份、状态和正文，专用 Canvas 保存继承／分支／合并关系及布局；`data.json` 不保存项目影子真值。
- Base／Local／Remote 同字段竞争必须逐字段人工解决；凭证只存 SecretStorage，所有远端写入复用唯一队列和 `RemoteWriteGate`。
- 当前版本不展示项目投影入口；统一门禁覆盖后台扫描、队列、恢复、重试和冲突写回，历史操作只读保留且不阻塞普通任务。
- Project／Stage 扫描仅解析含顶层 `helix-kind` 的 frontmatter；普通正文与聚焦块不解析、不改写，Helix 元数据仍严格校验。
- Project／Stage／Canvas 自写事件经 quiet-window 合并为一次稳定重扫；外部事件和失败仍会触发检查。
- Canvas 摘要与阶段编号账本是可重建缓存，可在稳定 CAS 后静默修复；缺失节点、关系变化和迁移仍需人工确认。
- 既有复盘每次打开会重算明确 marker 内的统计；缺失/重复 marker 时不改正文，模板只用于首次创建。
- 普通任务关联只保存远端任务 ID 与 Helix 项目／阶段 ID，不依赖项目投影或清单映射；保存／重绑须远端复读并使用 Markdown revision CAS。
- 项目页按当前项目展示关联任务及阶段；任务移至其他滴答清单不会破坏关联，缓存缺失不推断远端删除。
- 复盘关闭事件以笔记路径作为确定性 occurrence，同一复盘不会重复计分；摘要和近 14 日分析展示完成复盘数。
- 版本兼容基线为 Obsidian桌面端 `1.12.2`；版本文件均已登记 `0.1.5`。
