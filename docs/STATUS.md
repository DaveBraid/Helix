## 当前事实

- Project／Stage Markdown 保存项目、阶段身份、状态和正文；专用 Canvas 保存继承／分支／合并及布局；`data.json` 不保存项目影子真值。
- Stage `# 计划行动` 的顶层清单项自动进入任务页，缩进项作为子任务；首次读取会静默补稳定身份，空模板占位保持原样。
- 本地任务详情采用 Dense task canvas，支持日期月历、无时间／时间点／时间段及子任务增删改排；全部通过 Stage revision/CAS 写回原 Markdown，不建立第二份真值。
- 阶段卡片主体保持中性；同项目只用项目色顶部细条、边框和轻阴影；五状态只用图标、文字和语义色。
- 项目容器使用统一 1 px 边框；阶段卡片使用 4 px 项目色顶边。
- 项目与阶段状态使用原位 5 项 Helix 菜单：按钮保持卡片原外观，选项以 4 px 等距分隔，菜单跨 Canvas 指针事件持续打开；点击外部或 Escape 关闭。
- Stage／Project 正文输入期间不运行派生项目扫描；失焦后合并刷新。后台 Helix 标签只缓存服务状态，重新成为活动叶子时才渲染，禁止后台页面抢走编辑焦点。
- 项目启动扫描等待 Obsidian `onLayoutReady` 后读取双稳定快照；布局就绪前禁止项目写入，避免用不完整 Markdown 索引制造 Canvas 身份假冲突。
- 阶段卡片操作栏提供新增、连接、折叠、删除；关系拖拽、连线和相机逻辑保留。
- 聚焦桥接以 Canvas 入边为关系源，支持继承、分支、合并、反向编辑及同窗竞争冲突。
- 冲突中心按“需要你选择／等待远端核对／仅需检查”分组；文本使用真实行号 IDE diff，标量属性按需展开。
- 当前版本不展示项目滴答投影入口；统一门禁覆盖后台扫描、队列、恢复、重试和冲突写回。
- 凭证只存 SecretStorage；版本 `0.1.6`，最低 Obsidian 桌面端 `1.12.2`。
