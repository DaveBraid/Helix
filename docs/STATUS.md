## 本轮目标

- 发布可供本人长期使用的 `1.0.0` 本地正式版，并保持 Markdown／Canvas 为唯一真值。
- 非目标：不开放滴答网络同步或项目投影，不访问滴答远端，不修改正式 Vault，不发布到 Obsidian 社区。

## 当前事实

- Project／Stage Markdown 保存身份、状态和正文；专用 Canvas 保存关系及布局；`data.json` 不保存项目影子真值。
- Stage `# 计划行动` 的顶层清单项自动进入任务页，缩进项作为子任务；首次读取会静默补稳定身份，空模板占位保持原样。
- 本地任务详情采用 Dense task canvas，支持日期月历、无时间／时间点／时间段及子任务增删改排；全部通过 Stage revision/CAS 写回原 Markdown，不建立第二份真值。
- 项目色只用于容器／卡片细边；五状态使用原位菜单及语义图标。
- Stage／Project 正文输入期间不运行派生项目扫描；失焦后合并刷新。后台 Helix 标签只缓存服务状态，重新成为活动叶子时才渲染，禁止后台页面抢走编辑焦点。
- 项目启动等待 `onLayoutReady` 后读取双稳定快照；布局就绪前禁止项目写入。
- 阶段卡片支持新增、连接、折叠、删除、拖拽、连线和相机操作。
- 切换项目聚焦只增量更新选中态和相机；结构变化离屏构建后原子替换，避免整页闪烁。
- 普通任务与 Helix 项目／阶段的显式关联集中在任务页展示，项目页不再呈现关联任务面板。
- 关系图工具栏只在关系图显示；整理限定于项目或同项目选中阶段，保存只覆盖唯一 Canvas 布局。
- 双击容器聚焦项目；拖动标题整体移动；整项目删除需逐字确认并保护非托管关系。
- 三种用户关系名为推进、分支、合并；内部 `inherit` 保持稳定并兼容旧“继承”标签。
- 聚焦桥接以 Canvas 入边为关系源，支持推进、分支、合并、反向编辑及同窗竞争冲突。
- 聚焦引用在 Markdown 中只保留上下各一空行；Live Preview 折叠纯技术标记行，既有宽松空白会后台静默收敛。
- `helix-sequence` 保持物理文件高水位且不复用；`helix-stage-code` 按当前继承／分支／合并图维护，删除会原子更新现存 Stage 标题、属性、聚焦引用及 Canvas 编号索引。
- 冲突中心分级展示；文本使用真实行号 IDE diff，标量属性按需展开。
- `1.0.0` 为本地正式版：界面、命令、自动调度与服务网络入口统一关闭滴答同步；项目投影继续关闭，既有口令保留在 SecretStorage。
- 版本 `1.0.0`，最低 Obsidian 桌面端 `1.12.2`；通过 GitHub Release／BRAT 分发。

## 相关约束

- 权威源、Stage 本地任务及项目投影边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。
- 项目写入必须串行并使用 revision／CAS；不得覆盖未知正文或保存第二份本地任务真值。
- 本地子任务重排只允许同一父任务的直接子任务身份全集；身份缺失、重复或集合变化必须拒绝。
- 远端结果未知时禁止重试；同字段竞争必须逐字段人工选边。
- 真实滴答测试只可使用唯一合同标记和专用清单；不得删除、移动或覆盖用户已有远端对象。
