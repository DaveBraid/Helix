- 一个 Helix 项目对应一个带稳定 marker 的滴答父任务，阶段行动投影为父任务 `items`；旧 `parentId` 子任务模型已退出当前合同。
- 真实证据表明该账号整组更新 `items` 时会重生成全部检查项 ID；明确成功时，Helix 能按除 ID 外完整语义和相对顺序证明唯一双射，并将同父任务所有 owned ID 原子重映到 ledger 与相关 Stage Markdown。
- 每条 ledger 持久保存 Stage 路径；发送前读取并核对同父任务全部非 tombstone Stage 的身份、UUID 和旧 remoteId。缺席文件移动、删除、身份或 marker 变化会在零远端写入时阻断。

- Base／Local／Remote 同字段竞争必须逐字段人工解决；凭证只存 SecretStorage，所有远端写入复用唯一队列和 `RemoteWriteGate`。
