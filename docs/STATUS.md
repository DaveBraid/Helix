## 当前事实

- 任务、清单、习惯和专注记录以滴答为权威源；普通任务读取／同步、列表／看板和专注记录读取已有实现。
- Project／Stage Markdown 保存项目身份、状态和正文，专用 Canvas 保存继承／分支／合并关系及布局；`data.json` 不保存项目影子真值。
- Canvas 摘要与阶段编号账本是可重建缓存；稳定且权威文件可读时允许静默修复，关系缺失或身份竞争仍须人工处理。
- 聚焦桥接以 Canvas 入边为唯一关系源，支持继承、分支、合并、反向编辑和同窗竞争冲突；Live Preview 隐藏受管 HTML 标记。
- 普通任务可独立关联 Helix 项目／阶段，不依赖项目投影或清单映射；项目页展示关联任务及阶段，跨滴答清单移动不会改变远端任务 ID 关联。
- 复盘关闭事件以笔记路径作为确定性 occurrence；自动摘要和近 14 日分析共用事件聚合并展示完成复盘数。
- 当前版本不展示项目投影入口；统一门禁覆盖后台扫描、队列、恢复、重试和冲突写回，历史操作只读保留且不阻塞普通任务。
- 凭证只存 SecretStorage；所有远端写入复用唯一队列和 `RemoteWriteGate`；Base／Local／Remote 同字段竞争必须人工解决。
- 版本仍为 `0.1.5`，最低 Obsidian 桌面端 `1.12.2`。
