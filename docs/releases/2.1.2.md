# Helix 2.1.2

Helix 2.1.2 完善项目任务与滴答清单之间的安全同步，可从 `2.1.1` 直接升级；不迁移 Project／Stage Markdown 或 Canvas。

## 首次写入引导

- 首次启用滴答写入时提供明确认证与能力核验入口，不再把必要设置藏在开发调试区域。
- API 口令继续只存于 Obsidian SecretStorage；新设备、新 Vault 或能力合同变化后仍需重新核验。
- 未完成核验时，本地 Stage 及行动任务仍按 Markdown 状态正确展示，不依赖远端父任务存在。

## 项目任务投影

- 修复进行中 Stage 未稳定进入 `Helix Projects` 清单的问题。
- Stage 行动变更会刷新本地任务列表与父子任务详情；父任务完成状态继续由直属子任务派生。
- 项目投影复用现有任务、账本、CAS 和逐字段冲突机制，不建立第二份项目真值。

## 远端状态回写与性能

- 滴答中完成或重新打开已纳管子任务后，Helix 会在下一轮同步安全更新 Stage Markdown、任务列表和父任务进度。
- 同步同时合并活动任务与已完成任务结果，避免已完成项目从清单详情消失后无法回写。
- 本地与远端同时改变同一状态时继续进入逐字段冲突，不静默覆盖。
- 项目网络同步改用独立串行器；网络等待不再占用项目工作区全局写锁，避免整个 Helix 随请求延迟卡住。

## 数据与兼容

- Project／Stage Markdown 与专用 Canvas 的权威边界不变；未知 YAML、正文、非托管节点与非托管边不会被迁移。
- 最低版本仍为 Obsidian `1.12.2` 桌面端；不支持移动端。
- 升级不会自动启用滴答同步，也不会创建或清理测试对象。

## 已知限制

- 普通滴答子任务的新增、删除和排序仍取决于当前账号已验证的真实合同能力。
- 离线创建超时仍属于远端结果未知，必须人工确认，不能盲目重试。
- 本地任务暂不支持跨 Stage／项目移动。

## 上游与许可证

- 本版本未引入新的上游实现代码。
- 第三方归属与完整许可证见 Release 附件。
