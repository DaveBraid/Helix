## 已落实

- 项目正文、阶段正文、身份和状态以 Markdown 为唯一事实；节点布局和“继承、分支、合并”关系以唯一主 Canvas 为事实；`data.json` 不保存副本。
- 内嵌关系图不再把项目显示为与阶段并列的普通卡片；按项目当前可见阶段坐标绘制低调的自适应背景容器。容器标题打开项目 Markdown，并显示状态、阶段数和完成折叠入口；原生 Canvas 中既有项目托管节点继续作为兼容身份锚点保留，不被静默删除或改型。
- 项目可在创建时选择颜色，也可从项目切换条单独修改；颜色以规范 `#RRGGBB` 写入项目 Markdown 的 `helix-color`。卡片使用从左侧到中部淡出的低饱和渐变，右侧保持原主题背景。
- 物理阶段边是唯一结构事实。每次结构操作对完整边集重算显示关系：目标入度不少于 2 时全部入边为合并；否则来源出度不少于 2 时为分支；其余为继承。合并组 ID 由目标阶段稳定生成。
- 阶段卡片新增直接拖线连接；拖到已有阶段后先展示新增边、受影响节点和已有边重标数量，跨项目连接需独立确认。点击连接把手可通过下拉选择目标，保证键盘可达；自环、重复边和有向环零写入拒绝。
- 删除中间阶段默认计算“全部前驱 × 全部后继”的桥接计划，确认框列出新增、复用、跨项目和重标影响；桥接与不桥接分别保存精确的受影响节点及 `edgeId: before→after` 重标计划，切换时同步刷新。新增候选超过 24 条时默认并强制使用不桥接口径。桥接、全图关系正规化和受影响连通分量布局进入同一 Canvas after 镜像及既有删除事务日志。
