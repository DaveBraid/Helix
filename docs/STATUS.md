## 本轮目标

## 当前事实

- Project／Stage Markdown 保存项目、阶段身份、状态和正文；专用 Canvas 保存继承／分支／合并及布局；`data.json` 不保存项目影子真值。
- Stage `# 计划行动` 的顶层清单项自动进入任务页，缩进项作为子任务；首次读取会静默补稳定身份，空模板占位保持原样。
- 本地任务详情采用 Dense task canvas：面包屑、大标题、五项属性矩阵、子任务进度与列表；不显示备注区或时区文字。
- 本地任务日期使用 Helix 月历弹层，支持上下月、今天、清除和单击选定；不依赖平台原生日期控件。
- 本地任务时间支持无时间、时间点和同日时间段；空时间段完整显示 `--:-- – --:--`，未改日程时保持原时间与时区。
- 子任务支持完成、标题、日期、时间段、优先级、添加、删除和拖拽排序；保存使用同一 Stage revision/CAS，排序和元数据直接写回原 Markdown 标记，不建立第二份真值。
- 阶段卡片主体保持中性；同项目只用项目色顶部细条、边框和轻阴影；五状态只用图标、文字和语义色。
- 项目容器四边使用统一 1 px 边框；阶段卡片使用完整 4 px 项目色顶边，不再继承旧左侧色条定位。
- 项目与阶段状态使用原位 5 项选择器，直接走 CAS 与恢复门禁，不再弹出模态。
- 阶段卡片悬停、键盘聚焦或选中时，以同尺寸操作栏替换关系摘要，提供新增、连接、折叠、删除；现有关系拖拽、连线和画布相机逻辑保留。
- 聚焦桥接以 Canvas 入边为关系源，支持继承、分支、合并、反向编辑及同窗竞争冲突。
- 冲突中心按“需要你选择／等待远端核对／仅需检查”分组；文本使用真实行号 IDE diff，标量属性按需展开。
- 当前版本不展示项目滴答投影入口；统一门禁覆盖后台扫描、队列、恢复、重试和冲突写回。
- 凭证只存 SecretStorage；版本 `0.1.6`，最低 Obsidian 桌面端 `1.12.2`。
