## 当前事实

- 滴答清单是任务、清单、习惯和专注记录的权威源；Project/Stage Markdown 保存项目身份、状态与正文，专用 Canvas 保存关系与布局，见 [ARCHITECTURE.md](ARCHITECTURE.md)。
- 普通任务双向同步、清单／看板、任务编辑、习惯及专注读取已接入。
- 滴答写入合同版本为 5；旧合同、授权不符、结果未知或身份不明均冻结为只读。
- 项目投影写入只走现有授权租约、离线队列、同步引擎和唯一消费者；创建在远端发送前持久化稳定 client identity，中断创建不重发。
- `didaProjectionState` 是投影启用状态与精确目标的唯一配置源；投影默认关闭，当前没有 UI、自动触发或真实写入入口。
- 投影读取模型从当前 Project/Stage Markdown 派生；未受管行动必须显式纳管，标题和五状态编辑使用 Markdown CAS。
- 激活确认会重新读取稳定项目工作区、重新统计项目／行动，并双源复读精确远端清单与分栏；计数或远端变化会要求重新确认。
- 阶段必须属于指定项目，且 Markdown `helix-kind/helix-id` 精确匹配；跨项目或身份错配零写入拒绝。
- 结果未知和冲突沿用既有生命周期；解冻与收据清理 proof 原子落盘，启动或显式入口幂等清理，纯读取只展示 pending。
- 六份默认模板位于可配置目录 `Template/Helix/`；只补缺失文件，不覆盖现有模板。
- 项目页关系、状态、布局、折叠、颜色与阶段看板从 Markdown/Canvas 派生；写入受恢复模式、稳定双快照和 CAS 保护。

## 相关约束

- 凭证仅存 SecretStorage；不得进入仓库、`data.json`、日志、Markdown、Notice 或夹具。
- 用户 Markdown/Canvas 优先；只修改明确受管字段、块、节点和边，写前复核修订，冲突不得静默覆盖。
- 真实滴答测试仅限唯一标记的专用对象；未知结果、残留或身份不明立即停止。当前阶段不执行真实写入。
- Vault 测试数据可自动化操作；该授权不扩展到真实滴答既有数据。
