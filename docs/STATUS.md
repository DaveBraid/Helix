## 已落实

- 项目正文、阶段正文、身份和状态以 Markdown 为唯一事实；节点布局和“继承、分支、合并”关系以唯一主 Canvas 为事实；`data.json` 不保存副本。
- 项目页改为内嵌工作台，包含关系图、卡片和看板。卡片只显示摘要，点击标题打开 Markdown。
- 关系图读取完整 Canvas，按原生节点的坐标和尺寸投影，支持缩放、平移、多选和拖动；多卡拖动使用一次 Canvas 比较写入，竞争时回滚界面位置并显示错误。
- 顶部“新建阶段”已移除。每个阶段卡片右侧在悬停或选中时显示添加子阶段按钮；任意中间节点都可继续派生。单卡加号已去掉关系与前置阶段选单：无后继时直接推断为继承，已有后继时直接推断为分支，弹窗只填写阶段标题。
- 关系图多选两个及以上阶段后，点击其中任一卡片的加号会直接推断为合并；来源顺序使用当前拖动后的实时坐标。若所选来源已有继承后继，弹窗会预告并在同一提交中把这些继承边转换为分支。同项目合并只填写标题，跨项目合并会明确显示目标项目和外部来源并额外确认。
- 自动创建提交必须携带弹窗时的完整关系意图，并把推断快照与最终 Canvas revision 的哈希绑定；弹窗期间关系变化或两次读取间的竞争会在创建 Markdown 前拒绝。
- 新子阶段固定放在来源节点右侧 160 像素；继承保持同一行，新增分支排在已有分支下方，合并节点放在所有来源右侧并按中心线定位。
- 阶段卡片提供删除入口，必须二次确认；阶段 Markdown 移入仓库 `.trash`，Canvas 节点和所有关联边通过比较写入删除。项目的唯一阶段禁止删除。
- 删除合并来源时不再误删整组合并：三源合并缩减为两源；两源缩减为单源时，按剩余来源的其他后继自动改为继承或分支，并在确认弹窗中预告语义变化。Markdown 被并发改名时删除会停止并回滚 Canvas。
- 画布已有关系可直接选择，并在关系操作条中修改类型、前置阶段或删除；修改与删除继续执行 DAG、跨项目确认和 Canvas 比较写入校验。
- 项目状态已在项目切换条、关系图和卡片视图的项目卡片中显示；阶段看板通过项目切换条显示当前项目状态。“看板”明确命名为“阶段看板”。
- 新阶段自动编号为“阶段 X”，必须填写自拟标题；新文件使用 `Stage-XX.md`，标题格式为 `阶段 X · 自拟标题`。
- Canvas 保存每个项目的阶段编号高水位，删除或恢复最高阶段不会复用旧编号；弹窗显示的下一编号与实际分配一致。高水位容器、全部条目和 Markdown 阶段编号均执行安全整数校验。
- 新阶段使用 `helix-stage`、`helixNodeKind=stage` 和 `helixStageId`；旧 `Cycle-XX.md`、`helix-cycle` 与旧 Canvas 字段只做兼容读取，不静默改名。
- 新建项目会同时创建 `Project.md`、`Stage-01.md` 和 Canvas 节点；任一步失败会回滚本轮新文件。
- 新建阶段支持继承、分支和合并。第一次从空来源点击加号创建继承，之后再次点击同一来源会把既有继承转换为分支并新增一个自拟标题的阶段，不再一次创建两个分支或生成 A/B 名称。跨项目合并与旧数据迁移仍要求显式确认。

- 冲突中心保留 Base、Local、Remote 三方快照，逐字段选择后才允许提交；没有选择时禁止应用。
