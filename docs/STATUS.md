## 当前事实

- Project／Stage Markdown 是项目身份、状态、正文与本地任务的权威源；专用 Canvas 是关系和布局的权威源。
- 日常开发只在 `dev`；只有用户明确要求“发布新版”时才允许合入 `main`、打标签和发布 Release。
- `main` 当前正式版为 `2.1.0`；本轮关系图改进仅存在于 `dev`。
- Stage `# 计划行动`直接进入任务页并形成任意深度本地任务树；带子任务的父任务完成状态由直属子任务派生。
- 项目关系图支持推进、分支、合并、关系中插、项目显式排序、容器／阶段 Shift 吸附、作用域整理及布局保存读取。
- Canvas `helixProjectOrder` 维护自动布局的项目容器顺序；旧库无账本时按当前容器位置推导，新项目追加到末尾。
- 新建项目或阶段只设置新增节点 X/Y；所有既有托管节点的 X/Y 逐项保持不变，容器按节点外框自动扩展。
- 连续“推进”位于父节点右侧并继承其 Y；新分支从既有后继下方展开，合并位于最右父节点下一列且使用父节点平均 Y。
- 悬停阶段卡片时，当前卡片、所有反向可达父阶段及路径边保持原样；后继和无关卡片／边弱化，合并会保留全部上游分支。
- 悬停高亮仅是会话投影，不写 Markdown、Canvas、设置或撤销栈。
- 自动同步仍需显式启用；当前测试 Vault 的自动同步为关闭状态。
