## 当前事实

- Project／Stage Markdown 是项目内容权威源，专用 Canvas 保存关系与布局；`data.json` 只保存恢复和同步状态。
- Stage `# 计划行动` 顶层条目进入任务页，缩进条目为本地子任务；任务页不再展示“项目关联任务”板块。
- 滴答读取、普通写入、合同与项目同步共用 `HelixService`、持久队列、远端写门和单一消费者。
- 普通任务 CRUD、移动、完成／重开、真实父子关系、看板归栏及分栏创建已有当前授权 v13 合同证据。
- 项目任务目标固定为唯一精确名称 `Helix Project` 清单及 `Helix项目` 分栏；远端身份始终使用精确 ID。
- 每个 Stage 是一个远端父任务，标题等于阶段名；该 Stage 的计划行动是带 `parentId` 的普通子任务。Helix Project 本身不创建远端父任务。
- 自动目标准备与项目任务写入跟随普通“自动同步”总开关；关闭时扫描和 readiness 均停止。
- Stage／行动增删改复用普通任务队列和冲突流程；禁止按标题领养或未知结果重发。
- 版本仍为 `1.0.1`，最低 Obsidian `1.12.2`；当前只在 `dev` 开发，不发布。

## 本轮改动

- 删除任务页“项目关联任务”渲染入口与面板实现。
