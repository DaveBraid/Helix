## 当前事实

- Project／Stage Markdown 是项目内容权威源，专用 Canvas 保存关系与布局；`data.json` 只保存恢复和同步状态。
- Stage `# 计划行动` 顶层条目进入 Helix 任务页，缩进条目为本地子任务。
- 滴答能力按只读、普通任务写入、专用合同、项目投影分层；配置默认关闭，启用须版本化二次确认。
- 普通任务 CRUD、跨清单移动、完成／重开、逐字段冲突、重启队列和真实父子关系已有自动化及 v12 真实合同证据。
- 普通任务拉取或队列消费遇到 Local 与 Remote 已取得相同结果时直接推进 Base、清理队列且零重复写入；中断的普通写入重启后进入结果未知人工核对，自动同步不得重发。
- 普通任务连接使用内部 unknown／online／offline 三态；仅明确 transient 读取失败进入 offline，离线编辑只持久排队，成功同步后再消费；鉴权和限流不伪装为离线。
- 离线时冲突字段选择仍可保存为 staged，但应用在任何远端读取或 applying 认领前拒绝。
- 项目映射为带稳定 marker 的普通父 Task；Stage 行动映射为带稳定 `parentId` 和 marker 的普通子 Task，不使用父任务 `items`。
- 项目删除先经既有队列精确删除远端子任务及父任务；持久 tombstone 阻止未知结果重发和本地删除失败后的复活。
- 远端结果未知禁止重发；同字段竞争保存 Base／Local／Remote，必须逐字段人工处理。
- 版本 `1.0.1`，最低 Obsidian `1.12.2`；当前不发布。
