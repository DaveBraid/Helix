## 当前事实

- Project／Stage Markdown 是项目内容权威源，专用 Canvas 保存关系与布局；`data.json` 只保存恢复和同步状态。
- Stage `# 计划行动` 顶层条目进入任务页，缩进条目为本地子任务。
- 滴答能力按只读、普通写入、专用合同、项目投影分层；项目投影启用须 fresh 预览、版本化二次确认和运行态 readiness。
- 普通任务 CRUD、移动、完成／重开、冲突和父子关系已有 v12 合同证据。
- Local 与 Remote 相同时零写入；中断写入重启后冻结，不得重发。
- 连接使用 unknown／online／offline 三态；离线编辑只排队，字段选择可保存但联网前不得应用。
- 限流状态持久化；冲突中心显示截止时间，到期后只允许一次受控读取，成功前不消费写队列。
- 项目映射为稳定 marker 父 Task；Stage 行动映射为带 `parentId` 和 marker 的子 Task，不使用 `items`。
- 项目删除精确排队删除远端子任务及父任务；开放任务集合证明不存在，tombstone 阻止重发和复活。
- 结果未知禁止重发；字段竞争保留三方快照，必须人工处理。
- 版本 `1.0.1`，最低 Obsidian `1.12.2`；当前不发布。
