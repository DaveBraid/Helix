## 当前事实

- 任务、清单、习惯和专注记录以滴答为权威源；任务同步、列表／看板和专注记录读取已有实现。

- 一个 Helix 项目对应一个带稳定 marker 的滴答父任务，阶段行动投影为父任务 `items`；旧 `parentId` 子任务模型已退出当前合同。
- 真实证据表明该账号每次整组更新 `items` 都会重生成全部检查项 ID；`itemsRoundTripVerified` 是投影门禁，`itemIdStableVerified=false` 不阻塞投影。
- 明确成功时，Helix 按除 ID 外完整语义和相对顺序证明唯一双射，并将同父任务所有 owned ID 原子重映到 ledger 与相关 Stage Markdown；重复语义、歧义、字段变化、重排或批量 CAS 失败均冻结。
- 每条 ledger 持久保存 Stage 路径；远端发送前会读取并核对同父任务全部非 tombstone Stage 的身份、UUID 和旧 remoteId。缺席文件移动、删除、身份或 marker 变化会在零远端写入时阻断。
- 结果未知不得按标题、临时 ID、差集或语义猜测，也不得盲目重发；只允许精确复读、人工确认或使用 outcome=`verified` 的持久收据收口。
- Base／Local／Remote 同字段竞争必须逐字段人工解决；凭证只存 SecretStorage，所有远端写入复用唯一队列和 `RemoteWriteGate`。
